Models for The Wheatsheaf (games/village-inn), all CC0 (see the LICENSE files). Each is a
self-contained GLB: the pack's external buffers and its colormap texture embedded, and the model
wrapped in one node that scales (and turns and moves) it to KayKit's size, where a cell is 4 units.

- wall-cross, wall-window, wall-door, wall-doorway, fence: wall-wood-detail-cross,
  wall-wood-window-shutters, wall-wood-door, wall-wood-doorway-square, fence; scaled 4, turned 90
  degrees and moved 1.8 so they run along x through the middle of the cell edge, like KayKit's
- chimney (chimney-base, scaled 3, centred), stall-red (scaled 4)
